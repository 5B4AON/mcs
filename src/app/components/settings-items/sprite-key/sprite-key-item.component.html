Shows an interactive straight-key button at the bottom of the screen when there is enough space. Tap or click it to key Morse code just like a physical straight key — press and hold for dashes, tap briefly for dots. This is especially useful on touch-screen devices but works with a mouse on desktop too.
Triggers a line break in conversation views when a different name appears.
Optional. Overrides the default RX/TX colour in fullscreen views.
