9.1  What Is a PWA?

Morse Code Studio is a Progressive Web App (PWA) — a website that can be installed on your device like a native app, complete with a home-screen icon, its own window and the ability to work fully offline. A service worker caches the application code and core assets on first visit; other resources such as help pages and icons are cached on demand. Once cached, subsequent launches are instant with or without an internet connection.

9.2  Installing on Mobile

Android (Chrome / Edge / Brave)

  1. Open the app in Chrome.
  2. Tap the three-dot menu (⋮) → "Install app" (or "Add to Home screen").
  3. Tap "Install" to confirm.

iOS / iPadOS (Safari only)

Chrome on iPhone cannot install the app. Its "Add to Home Screen" only makes a shortcut that opens inside Chrome, with Chrome's toolbars. Chrome is fine for using the app in a tab; to get the full-screen app, install it from Safari:

  1. Open the app in Safari.
  2. Tap the Share button () → "Add to Home Screen" → "Add".

The app icon appears alongside your other apps and launches in a standalone window.

Install hint. On a phone or tablet where the app is not yet installed, the Try Morse guide on the main screen shows a yellow button: Use it as an app on Android, where it opens the browser's install dialog (with a More in Help link beside it), and Add to Home Screen on iPhone and iPad, where it opens these steps, because Safari has no install button to call. The hint never appears in the installed app. After you close the guide it stays closed; reopen it from the main menu with Try Morse.

9.3  Installing on Desktop

In Chrome, Edge or another Chromium browser:

  • Click the install icon (⊕) in the address bar, or
  • Chrome: Menu → Save and Share → Install Morse Code Studio…
  • Edge: Menu → Apps → Install Morse Code Studio

The app opens in its own window without browser chrome, giving you more screen space.

9.4  Offline Benefits for Field Operation

Once cached, no internet connection is needed. This is especially valuable for amateur radio field operation:

  • POTA / SOTA / Field Day — Decode, encode and key CW from remote locations with no cellular or Wi-Fi coverage.
  • Emergency comms — One fewer dependency on external infrastructure when networks are down.
  • Instant startup & battery savings — Everything loads from local cache; no network traffic means longer battery life.
  • No account or subscription — Free, open-source and runs entirely on-device with no data sent anywhere.
  • Any device you already carry — Your phone or tablet becomes a capable CW tool without extra equipment.

9.5  Updating the App

When you open the app while online, the service worker checks for updates automatically. New versions download in the background and activate the next time you restart the app — no reinstall needed.

9.6  Screen Settings

Open Settings → Other tab and expand Screen Settings. It has two switches, each saved per device profile and included in presets: Keep screen on and Auto full screen.

Keep screen on (Screen Wake Lock)

Mobile devices and laptops dim and lock the screen after a period of inactivity. During a CW session — especially when decoding or waiting for traffic — you may not be touching the screen for extended periods, yet you still need the display to stay on.

Morse Code Studio can use the browser's Screen Wake Lock API to prevent the device from turning off the display while the app is in the foreground. This is particularly useful for:

  • Decoding sessions — watching incoming CW text without needing to tap the screen periodically.
  • Keyer practice — using a paddle or straight key connected via MIDI or serial while the phone sits on the desk.
  • Field operation — keeping the screen readable in sunlight without it dimming mid-QSO.

How it works

  • When enabled, the app requests a wake lock as soon as it starts.
  • If you switch to another app or tab, the lock is automatically released by the browser. When you return, the app re-acquires it.
  • Switching it off releases the lock immediately.
  • The card shows whether the wake lock is currently active below the switch.
  • The app checks every few seconds, and whenever you return to it, that the lock is really held, and requests it again if not.
  • If the browser refuses the request, an amber warning appears on the main screen with a Keep screen on button to try again. The switch stays on; only you turn it off.

Browser support

The Screen Wake Lock API is supported in Chrome, Edge, Firefox 126+ and Safari 16.4+ (including iOS). If the browser lacks support, the card says Not available on this device.

Auto full screen (browser)

Auto full screen (browser) puts the whole browser page into full screen, hiding the address bar and tabs. It is not the same as the app's own full screen view (the conversation view opened from the menu), which works inside the page.

How it works

  • Switching it on asks the browser for full screen; switching it off leaves full screen.
  • Browsers allow full screen only after a tap or key press. Right after the app starts or reloads with the switch on, the app waits for your first tap or key press, or you can use the Tap for full screen button shown on the main screen. Its × closes the prompt without going full screen.
  • If you leave full screen yourself (Esc or a swipe), the app does not pull you back in. It asks again only when you switch the setting off and on, or the next time the app starts.
  • The card follows the real state of the browser, so it is correct even when you enter or leave full screen another way.
  • An installed app (see 9.2 and 9.3) already runs in its own window or full screen, so nothing is requested.

Browser support

It works in desktop browsers and in most mobile browsers, including Chrome on Android and iPad. The iPhone browsers have no full screen for web pages; there the card says Not available on this device. On iPhone, add the app to the Home Screen instead (see 9.7).

9.7  Using Morse Code Studio on iPhone

Morse Code Studio runs on iPhone. The sections below cover what is different there.

Which browser to use

Chrome is recommended for everyday use. Every browser on iPhone, Chrome included, is built on Apple's WebKit, so the features available are the same as in Safari. Only Safari can install the app as a full-screen app (see 9.2); Chrome's "Add to Home Screen" makes a shortcut that opens inside Chrome.

Starting and resuming audio

  • Press the Start audio button. iOS only allows sound to start after a touch, so the app never starts audio by itself without one.
  • After a phone call, an app switch or a page refresh, iOS pauses web audio. The status line then reads Audio is paused. The app retries by itself; if iOS still refuses, tap anywhere on the page or press a key (or tap Tap to resume audio) and audio continues.

No sound?

The ring/silent switch on the side of an iPhone can mute web audio. A web page cannot detect this switch, so the app cannot warn you when it is set to silent. If audio is running but you hear nothing, flip the switch so the orange mark is hidden and raise the volume. When no microphone input is in use, the app asks iOS to play sound like a media player, which usually avoids the problem, but not on every iOS version.

What is not available on iPhone

iPhone browsers do not offer these features, so their cards in Settings show Not available on this device and cannot be switched on:

  • MIDI input and output (no Web MIDI).
  • Serial input and output and WinKeyer (no Web Serial).
  • Vibration (no Vibration API).

The Setup Wizard follows suit: the MIDI keyer choice in the send guide is greyed out, and the Connect output hardware guide only explains that nothing can be set up here. Keyboard, mouse, touch and straight-key sprite keying, the sidetone, the CW tone detector, the microphone key and the online relay are available.

Keyboard, notch and rotation

  • Dialogs follow the visible screen, so a field you tap stays above the on-screen keyboard and no empty gap is left when the keyboard closes. Content stays clear of the notch and the home bar, also when you rotate the phone.
  • Text fields use at least 16 px type, so iOS does not zoom the page when you tap one. Pinch-zoom still works.
  • Long-pressing the key sprite or the on-screen touch keys keys Morse; it does not open a copy or selection menu. Text areas stay selectable.

Keeping the screen on and the relay

Screen Wake Lock works on iOS 16.4 and later (see 9.6). When you switch to another app or lock the phone, iOS can pause sound and network connections, including the online relay, until you return. Keep the app in the foreground during a session.
